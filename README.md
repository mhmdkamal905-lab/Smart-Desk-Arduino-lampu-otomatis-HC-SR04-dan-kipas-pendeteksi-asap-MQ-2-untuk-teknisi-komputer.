Smart Desk Berbasis Arduino untuk Teknisi Komputer
Deskripsi Proyek

Smart Desk merupakan proyek penelitian dan pengembangan meja kerja pintar berbasis Arduino yang dirancang untuk mendukung efisiensi, produktivitas, dan kenyamanan teknisi komputer dalam melakukan aktivitas perbaikan serta pemeliharaan perangkat komputer.

Proyek ini dilatarbelakangi oleh penggunaan meja kerja konvensional yang belum dilengkapi sistem otomatisasi untuk membantu aktivitas teknisi. Pengoperasian perangkat pendukung yang masih dilakukan secara manual berpotensi mengurangi efisiensi waktu, sementara kondisi pencahayaan dan sirkulasi udara yang kurang optimal dapat memengaruhi kenyamanan dan keselamatan kerja.

Untuk mengatasi permasalahan tersebut, Smart Desk dikembangkan dengan mengintegrasikan Arduino Uno sebagai pusat kendali, sensor ultrasonik HC-SR04 untuk mendeteksi keberadaan pengguna, sensor MQ-2 untuk mendeteksi asap, serta modul relay untuk mengendalikan lampu dan kipas secara otomatis.

Fitur Utama

- Pencahayaan Otomatis: Menggunakan sensor HC-SR04 untuk mendeteksi keberadaan pengguna sebagai dasar pengendalian lampu.
- Deteksi Asap: Menggunakan sensor MQ-2 untuk mendeteksi indikasi asap di area kerja.
- Kipas Otomatis: Mengendalikan kipas berdasarkan hasil deteksi asap melalui sistem Arduino dan modul relay.
- Integrasi Sistem: Menggabungkan sensor, mikrokontroler, dan perangkat keluaran dalam satu sistem otomatisasi.
- Pengujian Sistem: Mengevaluasi fungsi sensor, respons perangkat, dan keberhasilan sistem berdasarkan skenario pengujian.

Tujuan Pengembangan
Proyek ini bertujuan untuk menghasilkan prototipe meja kerja pintar yang dapat membantu teknisi komputer mengoperasikan perangkat pendukung secara otomatis, meningkatkan kepraktisan kerja, mendukung efisiensi penggunaan energi, serta membantu mengendalikan asap yang muncul selama aktivitas penyolderan.
Teknologi dan Komponen

- Arduino Uno
- Sensor ultrasonik HC-SR04
- Sensor asap/gas MQ-2
- Modul relay
- Lampu
- Kipas
- Perangkat pendukung dan rangkaian elektronika

**Kata Kunci:** Smart Desk, Arduino Uno, HC-SR04, MQ-2, otomatisasi, teknisi komputer, sistem tertanam.
